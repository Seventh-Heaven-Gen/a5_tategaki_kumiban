# A5 縦書き組版ツール

ブラウザ上でA5縦書きの組版・PDF出力ができるツール。

原作: [kanashiki1979/a5_tategaki_kumiban](https://github.com/kanashiki1979/a5_tategaki_kumiban)

## 機能

- 縦書きテキストをA5サイズでプレビュー・PDF出力
- 1段/2段組み対応
- 明朝体/ゴシック体 切替（Noto Serif JP / Noto Sans JP）
- 文字サイズ 8〜14pt
- 綴じしろ設定（ノド/両端）
- ヘッダー・フッター・ページ番号
- 左始まり（右綴じ）/ 右始まり（左綴じ）対応
- 段落頭の自動字下げ（「『（始まりは下げない）
- 縦中横（2桁数字の自動処理）

## 使い方

1. 本文を入力し、書体・サイズ等を設定
2. 「PDFで書き出す」を押す（数秒〜数十秒。サーバーでPDFを作ります）
3. ファイル名はヘッダー欄の文字になります

原稿が長くてエラーになる場合は、2回に分けてください。
サーバーが使えないときは「ブラウザの印刷で書き出す(予備)」から、余白「なし」・ヘッダーとフッターをオフにして保存できます。

## 仕組み

プレビューはブラウザのCSS縦書き（`writing-mode: vertical-rl`）で描画しています。
PDFは、同じHTMLをサーバー側のヘッドレスChrome（`api/pdf.js`、Vercel関数）で印刷して作るので、プレビューと同じ組みになります。

- `a5_tategaki_kumiban.html` — 画面とプレビュー
- `api/pdf.js` — PDF生成（puppeteer-core + @sparticuz/chromium）
- `vercel.json` — 関数の設定
